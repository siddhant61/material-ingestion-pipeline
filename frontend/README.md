# Material Ingestion Pipeline Frontend

This directory contains the frontend application for the Material Ingestion Pipeline system. It is built using React, TypeScript, and Vite, providing a user interface to interact with the backend services.

## Setup

To get the frontend application up and running, follow these steps:

1.  **Navigate to the frontend directory:**

    ```bash
    cd frontend
    ```

2.  **Install dependencies:**

    Install all required Node.js packages using npm:

    ```bash
    npm install
    ```

## Running the Application

Once the dependencies are installed, you can start the development server:

```bash
npm run dev
```

This command will start the Vite development server, typically accessible at `http://localhost:3000` (as configured in `vite.config.ts`). The application will automatically open in your browser.
